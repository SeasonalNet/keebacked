# Changelog

All notable changes to `keebacked` will be documented in this file.

The project follows Semantic Versioning.

## [Unreleased]

### Added

## [0.1.0] - 2026-08-02

### Added

- Linux inotify watcher with periodic reconciliation.
- Stable source snapshots and SHA-256-verified atomic publication.
- Independent versioned backup targets with marker validation and retention.
- Strict TOML configuration.
- TTY-aware human-readable logs, structured JSON logs, and optional ANSI level styling.
- Hardened container build and Docker Compose deployment example.
- SemVer-derived binary and image metadata.
